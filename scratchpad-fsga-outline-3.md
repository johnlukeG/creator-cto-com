# FSGA AI Skills Workshop — Your First AI Skill

**Bird's-eye deck outline**
**15 slides · 4 acts**
Designed for a 15–25 minute workshop segment.

**Audience URL / QR:** `creatorcto.com/fsga`

---

## Core Promise

You will leave with one AI Skill idea for work you actually do.

## Core Thesis

An AI Skill is reusable task expertise for a specific kind of work.

## Core Mental Model

A good Skill candidate is work with:

1. **Repeat rate** — it comes back often
2. **Judgment reload** — you keep reloading context, standards, examples, voice, rules, or decision criteria
3. **Useful output** — it produces something concrete
4. **First draft value** — a better first draft would save time

## Slide 4 — Prompt vs. Skill

**Eyebrow:** act one · distinction
**Title:** A prompt asks once. A Skill teaches the work.

**Two-column comparison:**

### Prompt
- Written in the moment
- Lives inside one conversation
- Useful for quick help
- You provide the context again next time

### Skill
- Created once and reused
- Carries task instructions
- Can include examples, files, standards, and workflow steps
- Helps the AI handle a familiar kind of task

**Bottom line:**
When the same task keeps coming back, the guidance should come back with it.

**Visual direction:**
- Clean two-column contrast
- Do not add "template" as a third category

**Speaker notes:**
- "Prompts are still useful."
- "A prompt is what you write in the moment."
- "A Skill is where you put the repeatable parts."
- "Steps. Rules. Examples. Format. Judgment."
- "If you keep explaining the same task, that is a signal."

**Transition:**
"So where do good Skills come from?"

## Slide 13 — The Skill Opportunity Calculator

**Eyebrow:** act four · first rep
**Title:** Should this become a Skill?

**Body:** Score one repeated task.

**Visual direction:**
Create a calculator / scorecard with four scoring sections.

### 1. Repeat Rate

How often does this task come back?

- **5** = Daily
- **4** = Weekly
- **3** = Monthly
- **2** = Quarterly
- **1** = Yearly or rarely

### 2. Judgment Reload

How much thinking do you have to reload each time?

- **5** = Audience, context, standards, examples, tone, and decision criteria all matter
- **4** = Several standards or context details repeat
- **3** = Some repeated judgment
- **2** = Mostly simple formatting or cleanup
- **1** = Little judgment required

### 3. Output Clarity

How clear is the useful finished thing?

- **5** = Very clear output with known examples
- **4** = Clear output, minor variation
- **3** = Mostly clear
- **2** = Fuzzy output
- **1** = Hard to describe what "done" means

### 4. First Draft Value

Would a stronger first draft save meaningful time?

- **5** = Yes, immediately useful with review
- **4** = Useful after light editing
- **3** = Helpful but needs revision
- **2** = Maybe useful sometimes
- **1** = Not worth drafting

**Total:**
- **16–20:** Strong Skill candidate
- **11–15:** Worth testing
- **6–10:** Maybe later
- **4–5:** Probably just prompt it

**Bottom line:**
The best first Skills usually score high on repeat rate, judgment reload, and first draft value.

**Speaker notes:**
- "This is the expanded version of the Repeat Test."
- "Pick one task and score it quickly."
- "Daily is separate because daily work compounds fast."
- "High judgment reload is the signal that a Skill can help."
- "If the output is clear and a draft would help, it is probably worth testing."

**Transition:**
"Once you score it, give it a name."
