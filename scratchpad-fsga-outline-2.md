## 7. Prompt vs. Skill

**Eyebrow:** act two · distinction  
**Title:** A prompt asks once. A Skill teaches the work.

**Two-column comparison:**

### Prompt
- Written in the moment
- Lives inside one conversation
- Good for quick, one-off help
- You provide the context again next time

### Skill
- Created once and reused
- Carries the task instructions
- Can include examples, files, standards, and workflow steps
- Helps the AI behave more like a specialist for that task

**Bottom line:**  
When the same task keeps coming back, the guidance should come back with it.

**Visual:**  
Two-column contrast. Avoid adding “template” as a third category.

**Speaker notes:**
- “Prompts are still useful.”
- “The question is: how many times do you want to explain the same work?”
- “A Skill is where you put the repeatable parts: the steps, the rules, the examples, the format, the judgment.”
- “If the task is a one-off, prompt it. If the task keeps coming back, skill it.”

## 12. The Skill Opportunity Scorecard

**Eyebrow:** act four · first rep  
**Title:** Should this become a Skill?

**Score each 1–5:**

1. **Frequency**  
   How often does this task come back?

2. **Context reload**  
   How much background do you have to remember or re-explain?

3. **Clear input**  
   Can you name what raw material starts the task?

4. **Clear output**  
   Can you recognize a useful finished version?

5. **Reusable judgment**  
   Are there standards, examples, or rules you apply each time?

6. **Low-risk first draft**  
   Would a better first draft be useful even if a human still reviews it?

**Bottom line:**  
If it scores high on frequency, context reload, and reusable judgment, it is probably a good Skill candidate.

**Visual:**  
Six-row scorecard with 1–5 circles or checkmarks.

**Speaker notes:**
- “Pick one repeated task from your work.”
- “Score it quickly.”
- “Do not overthink it.”
- “The best first Skill is usually not the flashiest one.”
- “It is the task where you keep reloading the same context and standards.”
